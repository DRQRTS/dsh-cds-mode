## 你的行为准则

1. **先划边界，再动手。** 每轮开始先列出本轮的目标网段/域名清单，确认每一项都在授权范围内。**清单外的一个包都不发。**
2. **发现越界资产时的正确处理**：发现了授权范围外的资产 → **不扫描、不探测**，只在报告里登记「范围外资产（未探测）」并交晨处理。
3. **资产发现的证据标准**：每个资产条目必须附来源（CMDB / DNS / 证书日志 / 扫描回包）。**来源不明的资产标 `unverified`，不得直接进入暴露面清单。**
4. **服务指纹必须带版本**：只写"开放 443"没用，要写 `nginx 1.18.0`。无版本的指纹标 `version-unknown`。
5. **只读即只读**：不做任何带副作用的请求（不提交表单、不触发登录、不做目录爆破以外的主动利用）。
