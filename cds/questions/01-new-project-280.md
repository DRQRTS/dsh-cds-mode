# 新项目需求题库（70–280 题）

> **本文件是素材，不是脚本。** 先读 [`99-adaptive-asking.md`](99-adaptive-asking.md)。
>
> **不要从 Q001 往下念。** 本文件有两个用途，都跟"顺序"无关：
> 1. **覆盖度检查表**——确保九大提问域没被漏掉；
> 2. **问法参考**——想不出怎么问时，看同类问题别人怎么问得让人答得出来。
>
> 真问题必须**依据用户已答内容现场生成**，接上这个项目的具体名词。判定表与生成方法见 `99-adaptive-asking.md` 第三、四节。
>
> 题量 **70–280 按需浮动**：信息够了就停，别为凑数硬问。

---

## 使用说明

### 标注格式

```
### Q003 · 项目代号
`D1` `L1-L4` `通用`
> 问题正文
- A. ...
- B. ...
```

- `D1`–`D9`：所属提问域（见下表）
- `L1`–`L4`：适用档位（`L1-L4` 表示全档通用）
- 标签：适用项目类型（`通用`/`web`/`app`/`桌面`/`CLI`/`插件`/`内容`/`API`/`数据`/`游戏`/`企业`/`开源`/`C端`/`B端`）

### 九个提问域（**必须全覆盖**，不得只问技术）

| 域 | 名称 | 题号区间 | 题数 |
|---|---|---|---|
| D1 | 身份与命名 | Q001–Q019 | 19 |
| D2 | 内容与功能 | Q020–Q056 | 37 |
| D3 | 商业性质 | Q057–Q081 | 25 |
| D4 | 使用范围与规模 | Q082–Q106 | 25 |
| D5 | 国家与地区 | Q107–Q127 | 21 |
| D6 | 语言与本地化 | Q128–Q147 | 20 |
| D7 | 开源与许可 | Q148–Q168 | 21 |
| D8 | 技术与约束 | Q169–Q239 | 71 |
| D9 | 验收与成功标准 | Q240–Q277 | 38 |
| **合计** | | | **277** |

### 抽取规则

```
1. 先按项目类型过滤（标签不匹配的整段跳过）。
2. 再按档位过滤（L4 跳过纯实现细节题；L1 跳过深度技术题）。
3. 按档位题量目标取数：
     L1 → 70–110   （技术域 D8 只取 8–12 题）
     L2 → 110–170  （D8 取 25–35 题）
     L3 → 150–220  （D8 取 60–80 题）
     L4 → 170–280  （D8 全部取，且追加"为什么/代价/三年后"追问）
4. 若某域题目被大量过滤，从 D8/D9 补齐题量；若 D8/D9 也不足，允许追加自定义题并编号 Q900+。
5. 分批给用户：每批 ≤ 5 题；每批后允许用户说"这个我不关心，跳过剩下的同类"。
```

### L1（零基础）表述替换表

抽取 L1 时，把问题正文替换为通俗版本：

| 原表述 | L1 替换 |
|---|---|
| 技术栈 | 用什么"工具"来做 |
| 部署 | 放到哪里让别人能用 |
| 数据库 | 数据存在哪里 |
| 接口 / API | 两块东西之间怎么传话 |
| 并发 | 很多人同时用会不会挤 |
| 鉴权 | 怎么确认"你是你" |
| 开源 | 代码给别人看、给别人用 |
| 许可证 | 别人能拿它做什么、不能做什么 |
| 响应式 | 手机和电脑上是不是都好看 |
| 依赖 | 借用了别人做好的零件 |

```md
### 需求项清单
- `R-001` [D1] 项目名称：云台记 · 来源 Q001A
- `R-002` [D2] 核心动作：用户上传工单照片并生成报表 · 来源 Q020A
- `R-014` [D6] 界面语言：中英双语可切换 · 来源 Q128C
  - 备注：与 R-022（只做中文内容）存在潜在冲突 → 已列入待澄清
```

**要求**：
1. 每条需求必须可追溯到具体题号与选项；
2. 冲突项必须显式标注；
3. 用户跳过的问题必须记录为「未采集」，不得默认填值；
4. 与用户确认后才写入 `.cds/requirement.md`。
