# 接手已有项目题库（约 120 题）

> **本文件是素材，不是脚本。** 先读 [`99-adaptive-asking.md`](99-adaptive-asking.md)。
>
> **不要从 T001 往下念。** 用途同新项目题库：覆盖度检查表 + 问法参考。
> 接手项目的问题尤其要**接到具体代码事实上**——A2 的逆向盘点结果就是最好的提问素材（"你这个 `list` 接口一次返回全部数据，我加筛选是在前端做还是后端做？"）。

> 适用：存在既有代码、用户给仓库/目录、用户说「接手 / 维护 / 接着做」。
> 与 `01-new-project-280.md` 的关系：**不重复问新项目通用题**，只问"接手特有"的部分。
> 通用部分（商业性质、国家地区、语言、开源许可）按 `01-new-project-280.md` 的 D3–D7 现场生成，**不要整域照搬**。

---

## 使用说明

```
总题量：通用 25–40 题（来自 D3–D7）
      + 接手专属 T1–T7（本文件，80–90 题）
      ≈ 105–130 题
```

按档位裁剪：
- **L1（完全不懂技术）**：只问 T1 全部 + T2 精选 10 题 + T3 精选 8 题（约 35 题），其余由 A2 的逆向调查代替。
- **L2**：T1 + T2 + T3（约 55 题）。
- **L3**：全部（约 110 题）。
- **L4**：全部 + 每题的"为什么/代价"追问（约 120 题）。

标注格式与 `01-new-project-280.md` 一致。

**差距比对（重要）**：晨必须把 T2 的「用户认知」与 A2 的「实际盘点」逐项对照，输出三类差异：

```md
### 认知差距表
| 项 | 用户以为 | 实际是 | 风险等级 |
|---|---|---|---|
| 技术栈 | Vue 2 | Vue 2 + 一堆 jQuery 混写 | S3（改造成本被低估） |
| 部署 | 云服务器 | 某人办公室的一台旧电脑 | S1（随时可能消失） |
| 备份 | 有备份 | 备份脚本早已失效 | S1（数据无保护） |
```

**这张表往往比代码本身更重要**。它必须进入 `research/00-整合资料.md` 并标注为「接手特有发现」。
